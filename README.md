# Afribot Ventures Ltd — Website

Live at https://www.afribot.co.ke

## Deploy (Vercel)
1. Upload every file and folder in this package to a GitHub repository (keep the folders `fonts` and `assets`).
2. In Vercel choose **Add New > Project**, import the repository and click **Deploy**. No settings need changing.
3. In **Settings > Domains** add `afribot.co.ke` and `www.afribot.co.ke`, then update DNS at Host Africa as Vercel instructs.

## Files
- `index.html` — the whole site
- `vercel.json` — security and caching headers
- `fonts/` — Fraunces and Figtree (self-hosted)
- `assets/` — logo marks
- `og-image.png`, `favicon*` — sharing image and icons
- `robots.txt`, `sitemap.xml` — search engines
