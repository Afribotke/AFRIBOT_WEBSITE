## Deployment

### Deploy to Vercel (Recommended — One Click)

1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) → **New Project**
3. Import your GitHub repo
4. Vercel auto-detects the static site — click **Deploy**
5. Go to **Settings → Domains** → add `afribot.co.ke`
6. Update DNS on Host Africa with Vercel's nameservers

### Deploy to Netlify (Alternative)

1. Go to [app.netlify.com](https://app.netlify.com)
2. Drag and drop this entire folder
3. Go to **Domain settings** → add `afribot.co.ke`
4. Update DNS on Host Africa
