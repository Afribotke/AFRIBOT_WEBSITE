# Afribot Ventures Ltd — Website

Live at https://www.afribot.co.ke

## Deploy (Vercel)
1. Upload ALL files in this folder to your GitHub repository (there are no sub-folders).
2. In Vercel choose **Add New > Project**, import the repository and click **Deploy**. No settings need changing.
3. In **Settings > Domains** add `afribot.co.ke` and `www.afribot.co.ke`.

## Files
- `index.html` — the whole site (logo and fonts are built in)
- `vercel.json` — security and caching headers
- `og-image.png`, `favicon*` — social sharing image and browser icons
- `robots.txt`, `sitemap.xml` — search engines
